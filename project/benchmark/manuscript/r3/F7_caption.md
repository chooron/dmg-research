# Figure 7 Caption (Journal of Hydrology Main Text)

**Figure 7 | Interpretive boundaries of same-coordinate specificity: residual advantage beyond parameter-rank similarity and functional-role limitation.**

**(a) Beyond rank similarity.** Scatter plot comparing same-coordinate parameter–information profile correspondence ($Q_{\mathrm{info}}(\text{diagonal})$, vertical axis) against rank-matched off-diagonal alternative parameters within the same model ($Q_{\mathrm{info}}(\text{matched off-diagonals})$, horizontal axis) across $n = 270$ parameter coordinates (35 multi-parameter conceptual models; single-parameter model *Collie-1* is structurally unmatched). For each parameter coordinate, the rank-matched baseline is defined as the mean information correspondence of the $k = 3$ nearest alternative parameters in raw parameter-rank distance ($Q_{\mathrm{rank}}$) with no caliper. Dashed diagonal line denotes 1:1 equality ($y = x$); shading highlights the upper half-plane where same-coordinate correspondence exceeds rank-matched alternatives. Same-coordinate correspondence consistently exceeds rank-matched alternative parameters ($\Delta = 0.295$, model-clustered 95% bootstrap CI: $[0.254, 0.429]$, sign-flip $p = 0.0004 < 0.001$, positive in 35/35 valid model summaries), confirming that cross-paradigm coordinate specificity is not a mathematical byproduct of raw parameter-rank continuity.

**(b) Functional-role boundary.** Paired model correspondence comparison between alternative parameters sharing the same conceptual hydrological functional role (left) versus alternative parameters belonging to different hydrological functional roles (right) across $n = 29$ conceptual hydrological models with valid role contrasts under the high-confidence functional taxonomy. Grey connecting lines represent individual conceptual models; purple diamonds and labels denote model-equal median correspondence (same-role alternative median: $-0.028$; different-role alternative median: $+0.005$). Dashed horizontal line marks zero correspondence. Belonging to the same hydrological functional role confers no additional correspondence advantage once exact coordinates are excluded ($A_{\mathrm{role}} = -0.119$, role-count-preserving permutation empirical $p = 0.806$, positive in only 12/29 models). Robustness testing under pre-specified HESS-prior role assignments confirms this boundary ($D_{\rho} = -0.00033$, 95% bootstrap CI: $[-0.00669, 0.02653]$, $p = 0.850$).
