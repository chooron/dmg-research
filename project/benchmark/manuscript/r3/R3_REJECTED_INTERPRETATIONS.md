# R3 Rejected Interpretations and Boundaries

The following statements are not supported by the frozen evidence and must not enter the manuscript as R3 conclusions.

| Rejected statement | Why it is not allowed |
|---|---|
| Physical meaning is preserved | `R_paired` compares association profiles, not physical semantics; model parameterizations are not a common physical coordinate system. |
| Functional role is preserved | After removing the original diagonal, same-role alternatives are not more similar than cross-role alternatives (`A_role=-0.1187969925`, `p=0.8057194281`). The HESS-prior flexible-role contrast is also null. |
| Parameter identity is preserved or recovered | Same-coordinate specificity is a label-alignment result, not proof of identity or equivalence of parameter meaning. |
| dPL strips noise | Raw rank continuity accompanies R3 correspondence, and no noise-removal estimand was tested. |
| dPL preserves informative ranking | The rank-linkage audit establishes residual specificity beyond rank matching, not informative-rank preservation. |
| IC is truth | IC is one calibration paradigm; IC-stable selection makes the 94.12% result conditional, not truth validation. |
| 94.1% of all relationships retain their sign | `94.12% = 849/902` is conditional on 902 cells selected using IC-only stability criteria, not all 5,420 cells. |
| `A_diag=0.615` is a conservative estimate of physical identity | It is an observed model-equal diagonal-versus-off-diagonal profile contrast under a frozen within-model label permutation. |
| The performance difference causes profile divergence | `abs(DeltaKGE)` conditioning is observational, potentially composition-sensitive, and cannot establish direction or mechanism. |
| `D_theta` proves a causal parameter-to-information pathway | The secondary bridge is mathematically coupled because the same parameter realizations enter both displacement and profile calculations. |
| dPL recovers IC physical roles or is physically superior | dPL has only canonical seed 42, and the products do not establish physical correctness or superiority. |
| The HESS compensation mechanism is reproduced | The role extension is a descriptive bridge with a null flexible-role result and lacks controlled process-omission/synthetic-truth evidence. |
| R3 proves causal information retention | All R3 findings are association-profile comparisons; no causal decomposition is identified. |

## Superseded or out-of-scope extensions

Broad functional-role continuity, parameter-meaning claims, all-cell sign-retention wording, the `A_diag`-as-conservative interpretation, dPL-noise-removal narratives, causal conditioning, and any new attributes, clusters, roles, compensation, seeds, training, recalibration, simulation, or R4 analysis are superseded/not for manuscript use. The authoritative historical source products remain preserved for provenance.
