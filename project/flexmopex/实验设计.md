# Results 实验大纲

## 3.1 Predictive adequacy and regularization path

本节目的：

**先证明 Flex-MOPEX 不是牺牲模拟能力换解释性，同时证明 alpha 能控制结构复杂度。**

需要做：

1. **模型性能对比**
   对比三类模型：

   | 模型               | 设置            |
   | ---------------- | ------------- |
   | Basic / baseline | 原始参数学习模型或最简结构 |
   | Flex-MOPEX       | 学习结构权重        |
   | Full model       | 四个候选过程全部激活    |

   每个模型跑 **5 seeds**。

2. **Flex 不同 alpha 路径**
   主 alpha：

   ```text
   0.005, 0.01, 0.03
   ```

   alpha path：

   ```text
   0, 0.001, 0.003, 0.005, 0.007, 0.01, 0.03, 0.05, 0.07, 0.1
   ```

呈现内容：

* KGE / NSE violin plot；
* KGE–complexity tradeoff；
* `sum_weight` 随 alpha 变化；
* active process count 随 alpha 变化；
* alpha=0.005/0.01/0.03 的性能损失和复杂度压缩表。

本节初步结论应是：

**Flex-MOPEX 在保持可接受预测性能的同时，形成了从 full structure 到 sparse structure 的可控 regularization path。alpha=0.01 作为主分析设置，0.005 和 0.03 作为敏感性设置。**

**学习到的结构坐标具有空间组织性，并且关键结构模式，尤其 snow-related share，需要在 multi-seed 下保持稳定。若 share_int 不稳定，可作为 limitation。**

## 3.3 Hydroclimatic controls on learned structural coordinates

本节目的：

**证明结构 share 不是图上好看，而是和流域气候、积雪、植被、地形、水文属性一致。**

   ```text
   share_sub

   ```

3. **机器学习解释**

**结构 share 呈现中等强度的 process-specific hydrological coherence。其中 snow 证据最强，phenology 有中等支持，subsurface 有组织性但需谨慎，interception 最弱。**

我觉得这个思路是对的，而且比单纯做“参数独立性检验”更适合 3.4。

它验证的不是：

**结构权重是否独立于参数。**

而是：

**结构权重表达的空间过程格局，是否能在参数空间中找到一致证据。**

这可以叫：

**convergent evidence from the parameter space**
或者
**parameter-space support for learned structural coordinates**

它的价值是：如果 `share_snow` 的空间格局和 full model 中 snow / temperature 相关参数的空间主轴一致，同时又比一堆参数更容易解释，那就能说明结构权重不是随便学出来的，而是对参数空间中已有水文组织的清晰化表达。

## 我建议 3.4 改成这个逻辑

标题可以是：

**3.4 Parameter-space support for learned structural coordinates**

或者：

**3.4 Structural weights as process-level summaries of parameter-space organization**

这一节回答：

**结构权重和 full model 参数空间是否指向相似的水文空间格局？**

这样比“独立性”更自然。

## 具体怎么做

### 1. 用 Full model 的参数作为 parameter-only reference

这个很好，因为 Full model 没有结构权重，所有过程都打开。

所以它可以代表：

**如果不显式学习结构权重，模型会如何通过连续参数表达流域差异。**

然后看 Flex 的结构 share 是否能总结这些参数差异。

---

### 2. 参数按过程分组

比如：

| 参数组                                    | 对应结构 share                 |
| -------------------------------------- | -------------------------- |
| snow / temperature 参数                  | `share_snow`               |
| ET / vegetation / seasonality 参数       | `share_phen`               |
| routing / groundwater 参数               | `share_sub`                |
| storage / interception / soil water 参数 | `share_int` 或 `sum_weight` |

每组参数可以做 PCA，取 PC1 / PC2 表示这一组参数的主要空间变化。

然后比较：

```text
share_snow vs full-model snow-parameter PC1
share_phen vs full-model ET/seasonality-parameter PC1
share_sub vs full-model routing/groundwater-parameter PC1
sum_weight vs full-model overall parameter complexity
```

---

### 3. 比较空间特性

可以做四类指标：

| 分析                   | 作用                   |
| -------------------- | -------------------- |
| 地图对比                 | 看空间格局是否一致            |
| Spearman correlation | 看 basin-level 排序是否一致 |
| Moran’s I            | 看空间组织强度是否相近          |
| 属性相关热图               | 看两者是否对应同一类水文属性       |

关键不是要求完全一致，而是看是否有：

**process-matched consistency。**

例如：

`share_snow` 和 full model 的 snow/temperature 参数主轴都指向 snow fraction、ERA5 snow months、高程等属性。

这就是很强的支撑。

## 这能解决什么问题

它可以回答 reviewer 的问题：

> 既然结构权重和参数耦合，为什么不直接分析参数？

回答是：

**Full model 的参数确实也包含相似水文组织，但这些信息分散在多个连续参数中，过程归属不直观；Flex 的结构权重把这种参数空间组织压缩成了少数几个过程命名的结构坐标。**

这正好和你现在 3.4 的压缩效率结果一致：5D structural summary 对 `frac_snow`、ERA5 snow fraction、`e_seasonality` 保留了 50 参数的大部分信息，但表达更直接。

第二，**Compression efficiency**

第三，**Interpretability advantage**

## 3.4 的核心逻辑

这节建议分成 4 个小问题。

### 3.4.1 Are structural weights independent of continuous parameters?

目的：

先正面交代：结构权重不是完全独立的信息通道。

需要做：

* `parameters → shares` 的预测 R²；
* `share–parameter` 相关矩阵；
* full-parameter residual attribute signal。

呈现内容：

* 表：`share_snow/share_phen/share_sub/share_int/sum_weight` 被 50 个参数预测的 R²；
* 一句话说明 residual signal 在 full-parameter control 后明显减弱或消失。

结论写法：

**结构权重与连续参数高度耦合，这是共同输入和共同水文损失下的预期结果，不应被解释为结构学习失败。**

不要写：

**结构权重独立于参数。**

---

### 3.4.2 Do structural weights provide compact process-level summaries of the parameter manifold?

目的：

回答 reviewer 的问题：

**如果权重只是参数摘要，为什么不直接分析参数？**

需要做：

比较不同特征集对流域属性的解释能力：

| 特征集                      | 维度 |
| ------------------------ | -: |
| 50 continuous parameters | 50 |
| first 5 parameter PCs    |  5 |
| best 5 raw parameters    |  5 |
| 4 shares + sum_weight    |  5 |

预测目标：

```text
frac_snow
frac_snow_months_era5
e_seasonality
runoff_ratio
baseflow_index
budyko_residual
aridity_index
```

呈现内容：

* 压缩效率表；
* retention ratio 图；
* 重点突出 snow 和 ET seasonality。

目前已有好结果：

* `frac_snow`：5D structure summary 保留约 91%；
* `frac_snow_months_era5`：保留约 84%；
* `e_seasonality`：保留约 94%。

结论写法：

**结构权重不是最优统计压缩器，但能用 5 个具有过程名称的变量保留高维参数中与 snow 和 evaporation seasonality 相关的大部分水文信息。**

### 3.4.3 Are structural coordinates supported by full-model parameter-space patterns?

目的：

补你刚才提出的思路：

**Flex 结构权重表达的空间格局，是否能在 Full model 的参数空间中找到一致证据？**

需要做：

1. 用 Full model 的参数作为 reference。
   Full model 所有过程全开，没有结构权重，所以它表示“没有显式结构坐标时，模型如何通过连续参数表达流域差异”。

2. 对 Full model 参数按过程分组：

| 参数组                                      | 对应结构 share                 |
| ---------------------------------------- | -------------------------- |
| snow / temperature parameters            | `share_snow`               |
| ET / vegetation parameters               | `share_phen`               |
| routing / groundwater parameters         | `share_sub`                |
| storage / interception / soil parameters | `share_int` 或 `sum_weight` |

3. 对每个参数组做 PCA，取 PC1 / PC2。

4. 比较：

```text
Flex share_snow vs Full snow-parameter PC1
Flex share_phen vs Full ET-parameter PC1
Flex share_sub vs Full routing-parameter PC1
Flex sum_weight vs Full parameter complexity / parameter norm
```

同时比较它们和流域属性的关系。

呈现内容：

* Full 参数组 PC1 空间图；
* Flex share 空间图；
* `share` vs Full parameter PC1 的相关表；
* `share` 和参数组 PC1 对同一属性的相关对照表。

结论写法：

**Full-model 参数空间中也存在相似的水文空间组织，而 Flex 结构权重将这种分散在多个参数中的组织显式表达为少数过程命名坐标。**

### 3.4.4 Does flexibility reorganize the learned parameter space?

目的：

回答你提出的新问题：

**结构权重进入模型后，连续参数的空间格局和属性关系是否发生变化？**

需要比较：

```text
Full model parameters
Flex model parameters, alpha=0.01
```

分析内容：

1. 参数分布变化

比较每个参数的：

```text
mean
std
IQR
extreme value fraction
spatial variance
```

2. 参数相关结构变化

比较：

```text
mean absolute parameter correlation
number of parameter pairs with |rho| > 0.7
parameter PCA effective dimension
```

3. 参数-属性关系变化

比较：

```text
corr(param_full, attributes)
corr(param_flex, attributes)
delta correlation = corr_flex - corr_full
```

重点属性：

```text
snow fraction
ERA5 snow fraction
e_seasonality
runoff_ratio
baseflow_index
aridity_index
```

4. 过程特异性转移

重点看：

```text
Full snow-parameter PC1 vs snow fraction
Flex snow-parameter PC1 vs snow fraction
Flex share_snow vs snow fraction
```

如果出现：

* Full snow-parameter PC1 与 snow 属性强相关；
* Flex 中 `share_snow` 与 snow 属性强相关；
* Flex snow-parameter PC1 相关减弱；

**Flex shifts part of the snow-related organization from continuous parameters into an explicit structural coordinate.**

* 参数-属性相关差异图；
* snow 过程转移示意图。

结论写法：

**引入结构权重后，模型可能改变了水文信息在连续参数和结构坐标之间的表达方式。结构权重不仅是参数摘要，也可能承担部分原本由连续参数隐式表达的过程差异。**

# 3.4 最终推荐结构

## 3.4 Structural weights as process-level summaries and reorganizers of parameter space

### 3.4.1 Coupling between structural weights and continuous parameters

说明权重不独立，但耦合是预期结果。

### 3.4.2 Compact process-level summaries of the parameter manifold

用压缩效率表证明 5D structural summary 保留 snow / ET seasonality 信息。

### 3.4.3 Parameter-space support from the full model

用 Full model 参数空间作为参照，证明结构权重和参数主轴指向相似水文格局。

### 3.4.4 Parameter reorganization induced by structural flexibility

比较 Full vs Flex 参数，分析结构权重是否改变参数空间组织。

# 3.4 的最终结论应该怎么写

最稳的结论是：

**Structural weights were not independent of the continuous parameters, but this coupling reflected the shared hydrological organization learned by the differentiable mapper. Compared with raw parameter inspection, the learned weights provided compact, process-named coordinates that summarized snow- and seasonality-related variation in the parameter manifold. Comparisons with the full model further indicated whether introducing structural flexibility reorganized part of the parameter space into explicit process-activation coordinates.**

中文：

**结构权重并不独立于连续参数，但这种耦合反映了可微模型共同学习到的水文组织。相比直接分析高维参数，结构权重提供了低维、过程命名的坐标，用来概括参数流形中与积雪和季节性相关的变化。与 Full model 的比较进一步检验了结构灵活性是否将部分原本隐含在连续参数中的过程差异转移到显式过程激活坐标中。**

## 3.5 Regional transferability toward ungauged basins

本节目的：

**验证结构坐标是否能迁移到未见水文气候区域，而不仅是在已训练流域上解释得通。**

1. **构建 7 个 hydroclimatic regions**

   第一版不做 multi-seed，先跑：


   | 方法                     | 含义                                |


**如果 Flex 在未见区域优于 global-mean 或 fixed structures，说明属性到结构坐标的映射具有区域泛化潜力。若结果一般，则保守写成初步 transferability test。**
