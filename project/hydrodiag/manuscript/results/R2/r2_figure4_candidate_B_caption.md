**Figure 4 (Candidate B). Derived parameter-space organization diagnostics between Base and CN model structures.**

**(a) Global signed paired parameter shifts ($\Delta z = z_{\text{Base}} - z_{\text{CN}}$).** Medians and 95% bootstrap confidence intervals (10,000 resamples across 531 basins) for all 15 shared parameters in normalized $[0,1]$ physical space for independent calibration (IC, warm orange circle) and differentiable parameter learning (dPL, deep blue square). The dashed vertical reference line indicates zero shift.

**(b) Boundary-concentration rate change ($\Delta \text{Boundary Rate} = \text{Rate}_{\text{CN}} - \text{Rate}_{\text{Base}}$).** Difference in the fraction of basins where parameter values lie within $\epsilon = 0.01$ of physical bounds between CN and Base structures, with 95% bootstrap confidence intervals. Positive values indicate increased boundary concentration under CN.

**(c) Normalized dispersion change ($\Delta \text{IQR} = \text{IQR}_{\text{CN}} - \text{IQR}_{\text{Base}}$).** Difference in parameter interquartile range across basins between CN and Base structures, with 95% bootstrap confidence intervals. Positive values indicate increased cross-basin parameter spread under CN.

*Note: All diagnostic metrics use normalized $[0,1]$ parameter values across 531 basins. Positive shifts (panel a) indicate larger parameter values in Base compared to CN. Boundary and dispersion changes reflect organizational properties of parameter distributions under distinct estimation paradigms.*
