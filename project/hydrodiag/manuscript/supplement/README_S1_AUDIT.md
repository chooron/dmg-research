# S1 audit package

Run from the project root:

```bash
source /home/jingxin/code/dmg-research/.venv/bin/activate
python manuscript/supplement/code/run_s1_audit.py
```

The audit is read-only with respect to model code, formal configurations, and existing results. Outputs are generated below `manuscript/supplement`. `UNRESOLVED` means that the repository did not provide executable evidence; it is not an inferred value. The local SWE preflight does not download large external data.
