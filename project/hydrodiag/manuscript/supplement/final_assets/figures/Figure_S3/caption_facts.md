# Caption facts — Figure S3

## Panel a
- Component-wise excess absolute truth-relative errors for all 15 shared XAJ parameters.
- Base and TGD are compared within IC and dPL facets.

## Panel b
- Component-wise excess NRMSE for `W_{U,t}`, `W_{L,t}`, `W_{D,t}`, `W_t`, `Q_{i,t}`, and `Q_{g,t}`.
- Positive values indicate greater deviation than the CN refit.

## Sample
- 531 catchments in the IC source; dPL seed values are combined per basin from seeds 42, 123, and 2026.
- State rows are test-period NRMSE rows.

## Symbols
- `Delta|e| = |e_M| - |e_CN|`.
- `Delta E = NRMSE_M - NRMSE_CN`.
- `W_t = W_{U,t} + W_{L,t} + W_{D,t}`.

## Uncertainty
- Error bars are 95% percentile bootstrap intervals from 2,000 basin draws.

## Visual encodings
- Base orange; TGD green/teal.
- IC filled circles; dPL open triangles.
- Grey vertical line marks zero excess.

## Interpretation qualifier
- Controlled truth-relative component error decomposition; not a performance ranking or real-catchment truth validation.
