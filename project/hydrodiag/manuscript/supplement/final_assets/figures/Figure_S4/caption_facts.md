# Caption facts — Figure S4

## Panel a
- Seasonal effective liquid-water input `P_t^*` is plotted by water-year month.
- Series are generating CN truth, Base, TGD, and CN under IC/dPL handling.

## Panel b
- Median signed storage deviation `Delta W_t = W_t(model) - W_t(truth)` is shown as a monthly heatmap.
- A heterogeneity inset reports row-wise IQR.

## Sample
- High-snow subset: `frac_snow >= Q75`, N = 133.
- Test period: 1995-10-01 to 2010-09-30.

## Symbols
- `W_t = W_{U,t} + W_{L,t} + W_{D,t}`.
- Water-year months run October–September.

## Uncertainty
- Panel (a) bands are source 95% CI bands.
- Panel (b) color is the source median; inset bars are source IQR.

## Visual encodings
- Base orange, TGD green/teal, CN blue, truth dark neutral.
- Solid/dashed line styles distinguish IC/dPL where applicable.

## Interpretation qualifier
- Descriptive seasonal pathway evidence from the controlled high-snow experiment; not a new model run or real-catchment truth validation.
